2. POSIX Permissions:

The required permission is 750.
- Owner (7): Read (4) + Write (2) + Execute (1).
- Group (5): Read (4) + Execute (1).
- Others (0): No access.
- Python Command: os.chmod(filename, 0o750)
- From this, I understand that the three digits represent the permissions of the Owner, Group, and Others.
