2. I/O Bound Concept:

An I/O Bound process spends more time waiting for input/output operations than performing CPU calculations.
- When a program needs data from the disk, it must wait for the disk to complete the read operation.
- During this time, the CPU can execute other processes that are ready to run.
- If there are no other processes ready, the CPU may remain idle while waiting for the I/O operation.
- From this, I understand that an I/O Bound program is limited by the speed of its input/output operations rather than CPU processing speed.
