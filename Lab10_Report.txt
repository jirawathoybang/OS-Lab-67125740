1. The Role of the Operating System:

From my experiment with `ultimate_cluster_os.py`, I learned that the Operating System manages resources to prevent problems and help AI workloads run efficiently.

- File System & Permissions (Lab 9): The program used os.path.isfile(dataset_path) to check whether the required dataset existed before starting a job. Workload D failed because secret_keys.txt was not found, so it could not continue.

- Memory Management (Labs 5/6): The program used a while loop to check whether enough RAM was available. If RAM was insufficient, the job had to wait instead of using more memory than the system could provide. This helped prevent memory overload and reduced the risk of Thrashing.

- Concurrency & Deadlocks (Labs 3/4): The program sorted the requested GPU IDs before acquiring their locks. This made jobs request GPUs in the same order and helped prevent Circular Wait deadlocks.

From these operations, I understand that resource management helps the system avoid unnecessary delays and prevents RAM and GPU resources from being overloaded.
